# Oscar Mulero Drums — Dark Functional Tools Pack 01

Pack MIDI extenso SOLO DRUMS inspirado en rasgos generales del lenguaje de Óscar Mulero:
techno oscuro, sobrio, mental, mineral, industrial, funcional y de presión progresiva.

No es un pack de samples. No contiene audio.
No contiene transcripciones exactas ni recreaciones de temas concretos.
Todo el material MIDI es generativo y original.

## Contenido

- 187 archivos MIDI en total.
- 182 clips MIDI de notas de batería.
- 5 clips MIDI CC para macros de batería.
- Loops de 4, 8, 16, 64 y 128 compases.
- Tempo principal: 136 BPM.
- Extras a 132, 134, 138 y 140 BPM.

## Uso recomendado en Ableton

1. Crea una pista MIDI con Drum Rack.
2. Asigna tus samples/sintes de drum a la tabla anterior.
3. Arrastra los MIDI a clips de la pista.
4. Usa `01_Kick_Engines` para construir el low-end rítmico.
5. Usa `03_Hypnotic_Top_Loops` y `04_Metallic_Percussion` para capas.
6. Usa `02_Dark_4x4_Grooves` como grooves completos.
7. Usa `05_Broken_Dark_Tools` para variaciones menos obvias.
8. Usa `08_Drum_Arrangements` como esqueletos de tema.
9. Usa `10_Drum_CC_Macros` para automatizar Drum Rack macros.
