# Oscar Mulero — Linear Hypnotic Fast Drums & Percussion Pack A

Pack MIDI centrado en batería y percusión para techno lineal, rápido, hipnótico y funcional.
Está pensado para patrones de pista con groove y enganche: menos ambient, menos breakdown,
más motor repetitivo, percusión lineal, capas rápidas y pequeñas mutaciones.

No contiene audio ni samples. Es solo MIDI.
Todo el material es generativo y original.

## Contenido

- 301 archivos MIDI en total.
- 293 clips MIDI de notas drum/percussion.
- 8 clips MIDI CC para macros de batería/percusión.
- Loops de 4, 8, 16, 32, 64 y 128 compases.
- Tempo principal: 140 BPM.
- Extras a 136, 138, 140, 142 y 144 BPM.

## Uso recomendado

- Usa `02_Hypnotic_Percussion_Grids` y `03_Percussion_Only_Hook_Loops` para enganchar encima de un kick.
- Usa `04_Linear_Full_Drum_Grooves` como patrones completos.
- Usa `05_Body_Tom_Propulsion` para dar cuerpo y empuje sin bajo.
- Usa `07_Top_Percussion_Drive_Combos` para añadir marcha.
- Usa `08_Peak_Linear_Tools` para secciones de máxima presión.
- Usa `10_Long_Linear_Drum_Perc_Arrangements` para estructuras de 64/128 compases.
