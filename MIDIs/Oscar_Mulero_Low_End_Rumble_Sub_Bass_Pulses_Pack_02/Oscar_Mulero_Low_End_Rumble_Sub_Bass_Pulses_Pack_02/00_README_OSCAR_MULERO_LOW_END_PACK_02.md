# Oscar Mulero Low-End — Rumble, Sub & Bass Pulses Pack 02

Pack MIDI extenso centrado en low-end: rumble triggers, sub pulses, bajos mono,
stabs graves, drones oscuros, patrones broken y arreglos largos.

Este ZIP no contiene audio ni samples. Es solo MIDI.
Está pensado para Ableton Live, especialmente para:
- una pista de rumble/sub,
- una pista de bajo mono,
- una pista de drone/textura grave,
- clips MIDI CC para macros de filtro, drive, decay, sidechain/gate y envíos.

## Contenido

- 180 archivos MIDI en total.
- 174 clips MIDI de notas low-end.
- 6 clips MIDI CC para macros low-end.
- Loops de 8, 16, 64 y 128 compases.
- Tempo principal: 136 BPM.
- Extras a 132, 134, 138 y 140 BPM.

## Uso recomendado en Ableton

### Pista 1 — Rumble Trigger

Usa los archivos de `01_Rumble_Triggers`.
Ruta sugerida:
- sinte o sampler con nota grave,
- reverb corta/media,
- filtro low-pass,
- saturación,
- sidechain fuerte contra el kick.

### Pista 2 — Mono Bass / Sub

Usa:
- `02_Sub_Pulse_Engines`
- `03_Low_Stabs`
- `04_Tunnel_Bass_Lines`
- `06_Broken_Low_End`
- `07_Call_Response_Low`

Ruta sugerida:
- sinte mono,
- una sola voz,
- glide muy corto o apagado,
- filtro bajo,
- saturación moderada,
- sidechain/gate.

### Pista 3 — Drone / Texture

Usa `05_Drones_And_Textures`.
Ruta sugerida:
- sinte mono o sampler granular,
- filtro automatizado,
- distorsión suave,
- reverb muy filtrada,
- volumen bajo.

## Notas usadas

Las notas giran principalmente alrededor de:

```text
D0, Eb0, F0, Gb0, Ab0, C1
D1, Eb1, F1, Gb1, Ab1, C2
```

La idea es gravedad, tensión y presión, no melodía evidente.

## Filosofía del pack

Este pack está pensado para construir el suelo del tema:
- rumble como extensión del kick,
- bajo mono muy sobrio,
- pocas notas,
- tensión entre F, Gb, Eb, D y C,
- drones graves para sensación de túnel,
- patrones rotos para salir del loop obvio,
- arreglos largos para directo o estructura completa.
