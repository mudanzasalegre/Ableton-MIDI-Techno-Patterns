# Oscar Mulero Transitions, Arrangements & Live Mutations Pack 04

Pack MIDI extenso centrado en estructura, arreglos, transiciones, herramientas de directo,
mutaciones y clips de automatización. Está pensado para combinarse con los packs anteriores:

- Pack 01: Drums / Dark Functional Tools
- Pack 02: Low-End / Rumble / Sub / Bass Pulses
- Pack 03: Mental Synths & Textures

Este pack no contiene audio ni samples. Es solo MIDI.
Todo el material es generativo y original.

## Contenido

- 267 archivos MIDI en total.
- 237 clips MIDI con notas/arreglos multitrack.
- 30 clips MIDI CC puros para automatización.
- Clips de 8, 16, 32, 64, 128 y 256 compases.
- Tempo principal: 136 BPM.
- Extras a 132, 134, 136, 138 y 140 BPM.
- Muchos archivos contienen varias pistas internas:
  - Drums / Transition Rack
  - Rumble / Low Atmosphere
  - Mono Bass / Sub
  - Mental Synth / Sequence
  - FX / Noise / Signals
  - Arrangement / Live Macro CC

## Concepto

Este pack no está pensado como una simple carpeta de loops. Está diseñado como una caja
de herramientas de arreglo:

- intros largas para mezclar desde silencio o desde otro tema,
- breakdowns sin kick,
- builds secos sin estética EDM,
- reentradas duras pero sobrias,
- outros y mixouts,
- mutaciones cada 8 compases,
- ladders de energía,
- puentes DJ,
- arreglos completos de 128 y 256 compases.

## Uso recomendado en Ableton

### Opción A — Usarlo como clip multitrack

1. Arrastra un archivo MIDI a Ableton.
2. Si Ableton lo importa como varias pistas, asigna cada pista a:
   - Drum Rack,
   - sinte de rumble,
   - bajo mono,
   - sinte monofónico,
   - FX/noise synth,
   - pista de macros CC.
3. Ajusta samples/sintes a tu paleta.

### Opción B — Cortar por secciones

Los archivos largos tienen marcadores MIDI de sección.
Puedes cortar cada 8, 16 o 32 compases y usarlo como escenas.

### Opción C — Live set

Los archivos de `07_Live_Mutations_8x8` están pensados para directos:
cada archivo tiene ocho bloques de 8 compases con capas que entran y salen.

### Opción D — DJ Tools

Usa:
- `01_DJ_Intros_32bar`
- `02_DJ_Intros_64bar`
- `06_Outros_Mixouts`
- `09_DJ_Mix_Bridges`

para construir material fácil de mezclar.

## Filosofía musical

La estética general es:
- arquitectura oscura,
- tensión progresiva,
- capas sobrias,
- pocos gestos obvios,
- breaks sin épica EDM,
- cambios por sustracción,
- presión mental,
- utilidad real para directo y mezcla.
