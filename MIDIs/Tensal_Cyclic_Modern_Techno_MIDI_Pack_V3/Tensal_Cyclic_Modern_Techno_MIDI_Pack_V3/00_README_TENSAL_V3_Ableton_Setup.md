# Tensal Cyclic Modern Techno MIDI Pack V3

Expansión MIDI original centrada en una lectura Tensal-like: techno cíclico, moderno, físico,
con sintes clásicos, texturas, percusión metálica, patrones off-kilter y bajo funcional.

Este pack complementa los anteriores de Surgeon/Counterbalance/Dynamic Tension.

## Contenido

- 28 archivos MIDI
- Grooves de batería
- Bajos mono
- Líneas de sinte clásico/cíclico
- Percusión metálica y atmosférica
- Arreglos de 64 y 128 compases
- Clips MIDI CC para macros de filtro, resonancia, drive, decay y envíos

## Tempo

Todo a 136 BPM, 4/4, 480 PPQ.

## Carpetas

### 12_Tensal_Cyclic_Modern
Base principal: 4x4 cíclico, hats de presión, metal grid y líneas de sinte cortas.

### 13_Tensal_Broken_Atmospheric
Patrones más off-kilter, rotos y atmosféricos. Útiles para intros, breaks o temas menos lineales.

### 14_Tensal_Analog_Modular_Lines
Líneas de sinte mono, pulsos modulares y patrones para automatizar filtro/drive.

### 15_Tensal_Hard_Driving
Material más directo y de pista: duro, seco y funcional.

### 16_Tensal_Arrangements
Estructuras largas:
- 64 compases cyclic modern
- 64 compases broken atmospheric
- 128 compases modern cyclic/modular

### 17_Tensal_CC_Macro
Clips de CC MIDI:
- CC74: filtro / brightness
- CC71: resonancia
- CC76: drive / macro
- CC91: reverb send
- CC93: delay/mod send
- CC73: decay
- CC75: shape / contour

## Consejos de Ableton

- Usa Drum Rack para batería.
- Usa un sinte mono para `bass_*`.
- Usa otro sinte mono para `synth_line_*`.
- Mapea CC74/71/76 a filtro, resonancia y drive.
- Mapea CC91/93 a envíos de reverb/delay.
- No sobrecargues el arreglo: la gracia está en mutar pocos elementos durante muchos compases.
- La percusión metálica gana mucho con filtro paso banda, saturación y delay corto.

## Aviso creativo

Todo el MIDI es material generativo original. No contiene audio, samples, stems ni transcripciones exactas.
